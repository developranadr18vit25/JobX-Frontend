JobX Frontend

**JobX** is a modern and responsive frontend for a full-stack job portal application, built with **React.js** and **Tailwind CSS**. It provides an intuitive and user-friendly interface that enables job seekers to effortlessly browse, search, and explore job opportunities across different domains and categories.

The application focuses on delivering a smooth user experience through a clean UI, responsive layouts, and efficient client-side routing. Users can search for jobs using keywords, filter opportunities based on categories, and view detailed job listings in an organized and visually appealing format.

Designed with scalability and performance in mind, the frontend communicates seamlessly with a dedicated backend through REST APIs, making it easy to integrate authentication, job management, and other server-side features.

> **Note:** The backend for this project is maintained in a separate repository.



Features

* Search jobs using keywords, job titles, or roles.
* Browse jobs across multiple categories such as **Remote**, **MNC**, **Startup**, **Fresher**, and more.
* Responsive and mobile-friendly interface for a seamless experience across devices.
* Clean and modern UI built with Tailwind CSS.
* Dynamic job listings fetched from the backend.
* Fast client-side navigation using React Router.
* REST API integration for retrieving job-related data.
* Reusable and modular React components for better maintainability.
* Optimized layout for improved usability and performance.

Project Structure

The frontend is organized using a component-based architecture, making the codebase modular, reusable, and easy to maintain. Individual UI components, pages, and utility functions are separated to improve scalability as the application grows.



Backend Repository

The backend for JobX is available in a separate repository and provides the REST APIs used by this frontend.
